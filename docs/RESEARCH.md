适用范围：本次交付的三份数据文件

- `src/data/references.js` — 公开资料来源登记（7 条，3 个来源分组）

**一句话口径：本数据集是面向科普展示的公开资料整理，不是工程图纸，也不是实时遥测。未确认的数值一律写作“公开资料未确认”，不以估计值填充。**

## 1. 真实性分级（A / B / C / D）

| 级别 | 名称 | 含义 | 本项目使用范围 |
| --- | --- | --- | --- |
| A | 官方参数 | 公开官方资料可确认的尺寸、构型或功能 | 舱段长度/直径、发射与转位日期、太阳翼单翼面积与数量、机械臂长度/自由度/承载、轨道高度/倾角/周期、对接口数量 |
| B | 公开资料近似 | 依据公开报道、官方影像或科普资料推断的比例与数值 | 模型展开尺寸、睡眠区数量、飞船主要尺寸、并网供电与再生生保等公开表述 |
| C | 科普示意 | 舱内布局、设备机柜、管路走向等依据公开影像的重构 | 舱内分区、机柜与照明、外部管路、对接机构内部结构 |
| D | 动画模拟 | 运动时序与轨道演示 | 太阳翼展开时序、机械臂关节运动、装配历程动画、交会对接接近路径 |

分级同时写在每条部件记录的 `accuracyLevel` 以及逐条 `specs[].accuracyLevel` 上，未标注的规格项按“公开资料未确认”处理。

## 3. 刻意重构与近似（B / C / D 级）

### 3.1 外形与比例（B 级）
- 舱段外形、太阳翼根数与安装朝向、外部天线与辐射器位置：依据公开影像与官方发布画面还原。
- 核心舱“小柱段/大柱段”的分段长度、节点舱外形、资源舱长度：按公开影像比例重建，非官方尺寸。
- `modelDimensions` 为**演示模型包围盒近似值**（`x` 为轴向或展开方向），用于场景尺度与聚焦，不构成官方参数；核心舱 12.4 m / 实验舱 15.0 m 的太阳翼展开长度、5.4 m / 9.2 m 的展开宽度均属模型取值。
- 邻近飞行器（神舟、天舟）外形与主要尺寸为公开影像近似，B 级。

### 3.2 舱内布局与设备（C 级）
- 舱内实验机柜、储物单元、照明、通道、舱门与内部舱板布置，均为科普化重构，不代表真实舱内布局。
- 对接机构内部结构、捕获包络、转位机构安装位置与构型：公开资料未确认，模型仅表达“对接—转位—停泊”的概念关系。
- 电缆、流体管路、热控回路的走向为概念示意，不表示真实走线。
- 机械臂关节内部结构、驱动与传感配置为建模仿真，非工程还原。

### 3.3 运动与动画（D 级）
- 太阳翼展开的折叠时序、展开速度与锁定过程：动画模拟，非真实机构运动参数。
- 机械臂关节运动、预设姿态与组合臂作业过程：动画模拟。
- 建造历程动画、交会对接接近路径、转位轨迹与轨道运动：**科普示意，非真实轨道动力学，非实时遥测**。

### 3.4 数值口径
- 公开资料对同一参数存在多种表述时，优先采用官方媒体一致引用的数值，并在 `note` 中说明。
- 无法确认的数值（发射质量、发电功率、储能容量、机柜数量、载荷位数量、频段/码速率、散热能力、循环利用率、推进剂贮量等）统一写为 **“公开资料未确认”**，共出现 71 处。
- 未使用任何虚构的文章标题、文章编号、遥测数据或专有参数。

## 4. 明确未知的事项（不写入模型，不作推测）

- 各舱**舱内布局、实验机柜数量与编号、睡眠/卫生设施的具体位置**；

## 6. 来源核验状态与限制（重要）

- **网络限制**：本编制环境无法访问 `www.cmse.gov.cn`、`www.cnsa.gov.cn`（域名解析到非公网地址，请求被拒绝）。因此表中所有事实均依据：① 官方机构公开信息在项目资料中的既有表述；② 被广泛一致引用的公开报道；③ 通用航天工程常识。**没有从当前环境直接抓取页面文本作为证据**，也未引用任何无法访问页面的“原文引述”。
- **不伪造引文**：本文件与代码中不存在任何声称“摘自某页原文”的引述；`references.js` 的标题为页面泛称，制订来源与年份时已区分“机构门户”“项目资料提供链接”两类。
- **年份字段**：`REFERENCES[].year` 对机构门户表示整理/访问年份，对白皮书表示出版年份；不代表页面文章发表年份。
